#   pip install -r requirements.txt --break-system-packages

# These are the same packages Modules/cipher.py, Modules/caa.py, and
# Modules/dnssec.py will each individually offer to install on first run
# if missing. Installing them all up front via this file just avoids
# being prompted separately per module.
#

# Python standard library and need nothing from this file.

cryptography   # Modules/cipher.py - TLS certificate parsing

#                    with: go install github.com/projectdiscovery/httpx/cmd/httpx@latest
#                    cipher.py will also offer to run this install command
#                    for you automatically if httpx isn't found.
